# Cookie / Kuki — рабочее название

Платформа онлайн-записи и автоматизации небольшого сервисного бизнеса. Название продукта не утверждено.

## Статус
Продуктовая концепция и архитектурное направление обсуждаются. Этот репозиторий является единым источником продуктовой документации и кода.

## Для кого
На старте — небольшие салоны с 2–10 сотрудниками. Позже возможны другие сервисные компании.

## Основные принципы
- Минимальное техническое ядро без бизнес-сущностей и бизнес-логики.
- Все бизнес-функции реализуются как версионируемые подключаемые модули.
- Монорепозиторий и модульный монолит в первой версии; возможное выделение модулей в самостоятельные сервисы.
- Общий клиентский интерфейс и API для Telegram Mini App, публичной страницы записи и встроенного виджета.
- Независимые канальные адаптеры для мессенджеров и AI.
- Развёртывание в двух моделях: облако (подписка) и собственный сервер (лицензия).
- Управление записями должно быть согласованным и атомарным, независимо от интерфейса.
