# ADR-0006 — Одна кодовая база для SaaS и self-hosted

**Статус: PROPOSED** · Issue #35 и #36 · REQ-014.

## Цель
Не поддерживать две разошедшиеся редакции продукта. Различаются конфигурация, hosting, entitlement и бизнес-договор, а не исходная предметная логика.

## Предлагаемое решение
Общий versioned release + manifest установленных modules. SaaS multi-tenant deployment; self-hosted Docker Compose, по умолчанию одна организация, отдельная БД/volume, Backup/Restore, TLS/reverse proxy, CLI/admin onboarding. Module entitlement реализован отдельным platform provider, а не kernel.

## Правила лицензирования
Бессрочная лицензия означает использование определённой версии продукта по лицензионному договору. Исходный код может предоставляться отдельно по условиям договора, не влечёт исключительных прав или бесплатных обновлений. Подписка включает доступ к размещённой версии на время оплаты с правилами экспорта и удаления данных. Зафиксировать grace/offline и обновления после юридического review.

## Нужны гарантии
Self-hosted работает без постоянного обращения к чужому лицензирующему серверу для основных операций. Метрики, отслеживание версии, rollback/migration, policies безопасности, эксплуатационные расходы прозрачны.

## Open
Процедура выдачи лицензий, допустимая самообслуживаемая установка, ответственность за ПДн, совместимость старых версий, доступность платных внешних провайдеров без аккаунта поставщика.
