# F1 Appearance publication authority (controlled-staging candidate)

Refs #223/#203, depends on #295. Issue #222 URL/guest proof is PROPOSED and is not implemented here. The existing Staff publication grant only authorizes the separate capacity workflow. The commercial base/premium configuration, prices, trial, public visibility/withdrawal and renewal semantics are not decided by this change.

Proposed engineering decision for synthetic controlled staging: an explicit privileged DB operator inserts a tenant-scoped grant with UUID and finite future expiry; revoke via setting revoked_at. There is no HTTP issue/renew/revoke or seeded grant, no default duration, and no grant automatically at signup. The published configuration command is opt-in through stagingPublicationEnabled, false by default, and the existing draft-only runtime remains unchanged. No fake entitlement callback, no automatic publication, and no public route. The real owner session and appearance.publish permission remain mandatory.

Lock order: current Identity/session policy -> staging Appearance grant SHARE -> branding row -> asset ownership locks. Re-read grant using DB clock after lock acquisition and again after publication/audit, before COMMIT. Concurrent revoke cannot commit across the locked command. Denied grant, unavailable storage or stale revision cannot modify the published revision. Record successful revision, grant, actor, correlation, timestamp in the same transaction; repeated revision returns the original publication and does not duplicate audit. Existing low-level store is a trusted internal capability, not public authority.

Migration 0042 reserved in #223/#203; reconcile with all active migrations before merging. Real signed Telegram/PG test covers no grant, expired fixture, live grant, idempotency and audit, revoked grant preserving previous published config, existing role denial. Deterministic concurrent grant revoke/expiry test and operator/audit/retention review remain necessary before any runtime activation. No production, public URLs or payments.
